Student Shield - Entity Relationship Diagram

Updated database schema reflecting normalized profile tables (students, counselors, admins)

The ERD shows the updated schema layout for StudentShield. The database has been normalized by splitting specific profile details out of the main users table. General authentication accounts are kept in users, while role-specific columns reside in the 1:1 subclass tables: students (links advisers, parent contact data, grade, section), counselors (email, phone), and admins (email, phone). Child tables like vent_logs, bully_reports, audit_logs, and sms_logs preserve historical logging by pointing directly to the respective record ID.

Table 1: Data Dictionary for Users
Field Data Type Description
id (PK) INT A unique auto-incremented identifier for each user.
name VARCHAR(255) The full name of the user.
password_hash VARCHAR(255) Bcrypt hash of the user password.
role TINYINT(1) User role identifier (0 = Student, 1 = Counselor, 2 = Super Admin).
remember_token VARCHAR(255) NULL Token for persisting the user session ("remember me" functionality).
created_at DATETIME Timestamp when the user account was created.
updated_at DATETIME NULL Timestamp when the user account was last updated.
Table 2: Data Dictionary for Students
Field Data Type Description
user_id (PK, FK) INT Primary key and foreign key referencing users.id.
student_id VARCHAR(50) UNIQUE Unique school-issued student identifier number.
parent_phone VARCHAR(50) NULL Phone number of the student's parent or guardian.
parent_email VARCHAR(255) NULL Email address of the student's parent or guardian.
section VARCHAR(100) NULL The student's class section or homeroom.
adviser_name VARCHAR(255) NULL Name of the student's class adviser.
grade_level VARCHAR(50) NULL The student's grade level (e.g., Grade 7, Grade 8).
created_at DATETIME Timestamp when the student profile record was created.
updated_at DATETIME NULL Timestamp when the student profile record was last updated.
Table 3: Data Dictionary for Counselors
Field Data Type Description
user_id (PK, FK) INT Primary key and foreign key referencing users.id.
counselor_email VARCHAR(255) NULL Email address of the counselor.
counselor_phone VARCHAR(50) NULL Phone number of the counselor.
created_at DATETIME Timestamp when the counselor profile record was created.
updated_at DATETIME NULL Timestamp when the counselor profile record was last updated.
Table 4: Data Dictionary for Admins
Field Data Type Description
user_id (PK, FK) INT Primary key and foreign key referencing users.id.
email VARCHAR(255) NULL Email address of the administrator.
phone VARCHAR(50) NULL Phone number of the administrator.
created_at DATETIME Timestamp when the admin profile record was created.
updated_at DATETIME NULL Timestamp when the admin profile record was last updated.
Table 5: Data Dictionary for Vent Logs
Field Data Type Description
id (PK) INT A unique identifier for each vent entry.
user_id (FK) INT References the user who submitted the vent (users.id).
raw_text TEXT The student's free-form emotional vent text.
emotions VARCHAR(255) NULL Comma-separated list of detected emotions from NLP analysis.
risk_percent DECIMAL(5,2) Calculated risk percentage representing distress severity.
risk_level VARCHAR(50) NULL Classified risk level (Low, Medium, High, Critical).
status ENUM('Pending', 'Reviewed', 'Flagged') Review status of the logged vent.
created_at TIMESTAMP Date and time the vent was submitted.
updated_at DATETIME NULL Timestamp when the log was updated.
deleted_at DATETIME NULL Soft-delete timestamp. NULL if active.
Table 6: Data Dictionary for Bully Reports
Field Data Type Description
id (PK) INT A unique identifier for each bullying report.
reporter_student_id (FK) INT NULL References the user filing the report (users.id).
reporter_type ENUM('self', 'bystander') Whether the reporter is the victim or a bystander witness.
victim_student_id (FK) INT NULL References the user who is the victim of bullying (users.id).
bully_student_id (FK) INT NULL References the user accused of bullying (users.id).
incident_details TEXT Detailed narrative description of the bullying incident.
evidence_file VARCHAR(255) NULL Path to uploaded file/image evidence.
status ENUM('pending_review', 'verified', 'rejected_fake') The current investigation status of the report.
created_at TIMESTAMP Date and time the report was filed.
updated_at DATETIME NULL Timestamp when the report was last updated.
deleted_at DATETIME NULL Soft-delete timestamp. NULL if active.
Table 7: Data Dictionary for SMS Logs
Field Data Type Description
id (PK) INT A unique identifier for each SMS log entry.
student_id (FK) INT References the student whose risk triggered the alert (users.id).
parent_number VARCHAR(50) The parent's phone number to which the SMS alert was sent.
alert_type VARCHAR(50) Type of notification trigger (e.g., High Risk Vent, Bully Incident).
message_content TEXT The full body text of the sent SMS alert.
sent_status VARCHAR(50) Delivery status: pending, sent, or failed.
timestamp DATETIME Date and time the SMS was dispatched.
Table 8: Data Dictionary for Email Logs
Field Data Type Description
id (PK) INT A unique identifier for each email log entry.
student_id (FK) INT References the student associated with the email alert (users.id).
recipient_email VARCHAR(255) The recipient's email address (e.g. parent email).
alert_type VARCHAR(50) Category of alert triggering the email.
subject VARCHAR(255) The subject line of the email.
message_content TEXT The HTML/Text content body of the email.
sent_status VARCHAR(50) Delivery status: pending, sent, or failed.
timestamp DATETIME Date and time the email was dispatched.
Table 9: Data Dictionary for Audit Logs
Field Data Type Description
id (PK) INT A unique identifier for each audit log entry.
user_id (FK) INT References the user who performed the logged action (users.id).
action VARCHAR(50) The logged action type (e.g. CREATE, UPDATE, DELETE, LOGIN).
entity_type VARCHAR(50) The table/entity name affected (e.g. vent_logs, bully_reports).
entity_id INT Primary key ID of the affected record in the entity_type table.
ip_address VARCHAR(45) NULL IP address of the client performing the action.
user_agent VARCHAR(255) NULL Browser or client user agent string of the requester.
created_at DATETIME Date and time the audit event occurred.

# DFD Level 0 (Context Diagram) — Explanation

The Context Diagram shows StudentShield as a central hub that connects students, staff, and automated services.

Students use the system to share their feelings anonymously, report bullying with evidence, and manage their accounts. To help keep everyone safe, the system sends venting text to a machine learning service that flags potential risks based on emotion and sentiment. 

Counselors and admins use the dashboard to track these insights, review cases, and manage the system. If a student is flagged as high-risk, the system immediately sends alerts to parents through both SMS and email, making sure help arrives as quickly as possible.
